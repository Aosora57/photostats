# PhotoStats —— 轻量本地照片统计查看器

为尼康相机照片库(JPG + NEF + 视频)定制的本地统计工具:扫描文件夹中的元数据,
在浏览器里以交互图表展示你的拍摄习惯,点击任何图表柱条即可筛选查看对应照片。

> 项目全景与后续规划见 **[进度总结.md](进度总结.md)**;开发者/交接请看 **[TECHNICAL.md](TECHNICAL.md)**(架构、代码地图、API、踩坑记录)与 **[目标1.md](目标1.md)**(路线图)。

## 使用方法

**双击 `启动统计.bat`** 即可:首次运行会自动扫描照片库(约 1-2 分钟),
之后自动打开浏览器进入 `http://127.0.0.1:8765`。

**服务的启停完全显式**:启动后会出现一个黑色控制台窗口——服务就活着,
**关闭那个窗口(或窗口里按 Ctrl+C)服务即停止**;也可以双击 `停止服务.bat`。
它不是系统服务、不会开机自启,不启动就零占用。

- 拍了新照片后,点界面右上角 **「重新扫描」**(增量,秒级),或关闭窗口重新双击 bat
  —— 启动时也会自动增量同步;右上角 **「年报」** 一键生成可分享的年度拍摄报告
- 以后想统计其他文件夹:`python photostats.py --root D:\其他照片目录`
- 只扫描不出界面:`python photostats.py --scan-only`
- 强制重新扫描:`python photostats.py --rescan`

## 统计内容

| 页签 | 内容 |
|------|------|
| 总览 | 照片/视频总数、容量、拍摄跨度、机身镜头数、RAW+JPG 成对率、快门数 |
| 拍摄参数 | 机身、镜头、焦段(35mm 等效)、光圈、快门、ISO、拍摄模式、测光、闪光灯、横竖构图比例、画幅比例(含机内裁切模式)分布 |
| 时间分布 | 按月趋势(照片+视频堆叠)、按年、一天 24 小时、星期分布、拍摄日历热力图(点击某天筛选) |
| 文件与存储 | RAW+JPG 配对(成对/仅RAW/仅JPG)、文件夹分布、疑似重复文件、视觉重复(pHash)、画质概览(严重糊片/过曝/欠曝,可点击筛选)、其他文件类型 |
| 题材统计 | AI 识别照片题材(人像/风景/动物/美食/建筑/夜景/街拍/微距/花卉/星空/其他),占比环形图 + 各题材横竖构图分布;支持把题材回写为 XMP sidecar(Lightroom 可读) |
| 人物 | AI 人脸检测与聚类(全部本机计算),人物头像网格,点击按人筛选照片 |
| 视频统计 | 数量/总时长/平均时长、4K 占比、分辨率、帧率、编码格式、时长分布 |
| 照片浏览 | 缩略图墙(含 NEF 缩略图)+ 内置筛选面板(机身/镜头/题材/构图/像素/画质/GPS/日期范围,多条件叠加),点击看大图和完整 EXIF,视频可直接播放 |

**顶部搜索框**:输入中文或英文描述(如"流星雨""猫""sunset")直接语义找照片。
**灯箱「🔍 相似」**:一键找出与当前照片最相近的连拍/同场景照片(选片辅助)。
所有图表**点击柱条即筛选**:筛选后所有图表联动重新聚合,照片墙同步过滤,
顶部出现筛选条,点「清除筛选」复位。

## 技术说明

- **零 pip 依赖**:仅用 Python 3 标准库 + 内置的 `tools/exiftool.exe`(13.59)
- 元数据由 exiftool 通过 UTF-8 argfile 批量提取,正确处理中文路径
- NEF 缩略图/预览图按需提取并缓存到 `cache/thumbs/`;JPG 无内嵌缩略图时直接用原图
- 无 EXIF 的文件(如剪辑导出的视频)拍摄时间用文件修改时间兜底
- 扫描结果缓存在 `cache/metadata.json`,重新扫描会整体重建
- 服务只监听 127.0.0.1,外部设备无法访问

## AI 题材识别

「题材统计」页签用 **CLIP 零样本分类**(ONNX 格式,`tools/models/` 内置模型,约 670MB)
在本机识别每张照片的题材,**照片不离开电脑、不联网**。

- 首次在「题材统计」页签点「▶ 运行识别」:全库约 10-20 分钟(视显卡而定),
  之后增量更新只处理新照片
- **GPU 加速**:自动检测 DirectML(任何 DX12 显卡,如 NVIDIA/AMD/Intel),
  本机 RTX 3060 上走 GPU;无显卡自动回落 CPU
- RAW 文件优先复用同组 JPG 的识别结果;无 JPG 配对的 NEF 自动提取预览图
  (缓存在 `cache/cls_previews/`,只提取一次)
- 依赖:`pip install --user onnxruntime-directml pillow numpy tokenizers`
- 修改 `classifier.py` 里的 `SUBJECTS` 类别定义后,旧识别结果会自动失效,
  重新点「运行识别」即可

## 文件结构

```
PhotoStats/
├── photostats.py      # 入口:扫描 + 启动服务
├── scanner.py         # exiftool 批量元数据提取
├── classifier.py      # CLIP 零样本题材分类(DirectML GPU 加速)
├── server.py          # 本地 HTTP 服务(界面/JSON/缩略图/视频 Range 播放/识别)
├── static/            # 前端(index.html + app.js + style.css + echarts.min.js)
├── tools/exiftool.exe # 元数据引擎
├── tools/models/      # CLIP ONNX 模型(视觉+文本+分词器)
├── cache/             # 扫描缓存 + 缩略图 + 识别结果(可整体删除,会自动重建)
└── 启动统计.bat        # 双击启动
```

## 已知限制

- 快门数读取自尼康机身内嵌数据(ShutterCount),非尼康文件显示为 "-"
- 横竖构图按"视觉宽高"统计:竖拍文件的存储尺寸是横向的,已按 EXIF Orientation 旋转标签自动换算
- 浏览器播放 HEVC(H.265)视频需要系统安装 HEVC 解码器;H.264 视频均可直接播放
- "疑似重复"依据"大小+尺寸+拍摄时间完全一致",相机双卡各拷一份这类情况会被正确找出
